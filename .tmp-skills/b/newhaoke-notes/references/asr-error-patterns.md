# ASR 转写常见错误模式

转写稿来源是 SRT 字幕文件，已经过口语书面化处理，ASR 错误较少。但以下专业术语错误仍可能出现，需在笔记撰写时留意修正。

**优先级**：撰写时遇到可疑术语，先在该节点对应的 PPT 文字中搜索（PPT 是老师准备好的材料，没有 ASR 错误），找到则以 PPT 为准；PPT 未提及才回退到本表 + 上下文推断。

## 口语到书面语的转换模式

| 口语表达 | 书面化处理 |
|---------|-----------|
| "这个东西就是说" | 删除，直接陈述实质内容 |
| "大家看 / 大家注意" | "教授指出" / "教授强调" |
| "对吧？" | 删除 |
| "嗯"、"然后"、"那个" | 删除 |
| "所以就是" | "因此" / "即" |
| "陈老师这里需要强调的是" | "教授强调" |
| "换句话来说" | "换言之" |
| "与此类似" | 保留，或改为"类似地" |

## 上下文推断原则

1. **先看 PPT**：当节课对应 `data/ppt_md/第N课_ppt.md` 通常含正确术语
2. **再看前后文**：上下文通常能提供足够的语义线索
3. **再看学科领域**：不同学科有特定的术语体系
4. **最后看句式**：常见论证结构可以帮助判断缺失或错误的词语

不确定时标注 `（转写不清，待确认）`，不要编造。
