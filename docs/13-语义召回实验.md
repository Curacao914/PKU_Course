# 13 · 语义召回实验（设计与预算）

> 状态：**实验骨架已就绪，真模型未跑**。本文回答"要不要上语义召回、上要怎么上、花多少钱"，
> 并给出可复现的实验管道 `tools/semantic-eval.mjs`。结论性数字必须来自真模型那一跑，
> 现在报告里的 stub 数字只证明**管道通**。

## 1. 为什么现在要谈这件事

词面检索（`packages/notes-mcp/src/search.mjs`）在这套笔记上做得不错：19 条开发集命中第一
100%。但**冻结留出集**（4 条语义等价、字面不同的问法，只用于报告）上 top1 0/4、top3 1/4：

| 问法 | 语料里的说法 | 词面为什么接不住 |
|---|---|---|
| 统计分析的分析对象是什么 | 分析单元 | "分析对象"与"分析单元"没有共同词 |
| 轻罪前科怎么处理 | 轻微犯罪记录封存制度 | 术语不同代 |
| 自然人为什么会成为国际刑法责任主体 | 个人刑事责任的确立 | 表述完全不同 |

开发集 100% 不是语义检索有效的证据（它是按语料措辞写的）。所以要么接受"字面对不上就查不到"，
要么做一个**有预算、有留出集、可回退**的语义层。

## 2. 单元选什么：小节，不是整篇

检索单元 = **小节**，来自发布时算好的 `sections`（Phase 5.2 A3）：

· 一节 300—800 字，语义集中；整篇 2 万字向量化会把一节的信息摊平；
· 每一节自带 **内容指纹**（FNV-1a）——它就是**缓存键**：重发一篇笔记，只有改过的小节需要
  重新向量化（发布时对比指纹即可）；
· 命中之后天然能给出"哪一节"，与词面检索的定位口径一致（`sectionId` = 页面锚点）。

实测规模（线上 11 篇发布库）：**353 个小节单元，约 15.5 万 token**。

## 3. 落点：低置信回退，不是替换

语义召回**不做默认路径**，只做"词面检索答不上来"时的回退：

```
词面检索命中且置信 → 直接用（可解释、零成本、零延迟）
词面检索零命中 / 只命中碎片 → 语义回退 → 结果必须标注「按语义近似召回」并给出相似度
```

三条理由：可解释性（读者/模型要知道"为什么是它"）、成本（每次查询都调 embedding 是浪费）、
可用性（embedding 服务挂了，站点与 MCP 必须照常工作）。

## 4. 评测协议（不许偷看留出集）

| 集合 | 用途 | 现在的结果 |
|---|---|---|
| 19 条开发集（`tools/retrieval-eval.mjs`） | 可以反复用来调策略 | 词面：top1 100% |
| 4 条冻结留出集（`tools/retrieval-holdout.mjs`） | **只报告，不调参**；一旦用它选策略就不再是留出集 | 词面：top1 0/4，top3 1/4 |

语义实验沿用同一套切分：`tools/fixtures/semantic-queries.example.json` 里 `report: true` 的
就是冻结那 4 条（外加一条开发用问法）。指标：top1 / top3 / 覆盖率（召回**期望课次**的比例）、
每查询延迟、每次索引成本。

## 5. 预算（真金白银，先看数）

索引一次性全量（353 小节 ≈ 15.5 万 token，按 1 token ≈ 1.5 汉字保守估）：

| provider | 价格 | 全量索引一次 | 每次查询 |
|---|---|---|---|
| 本地 stub（词面近似） | ¥0 | ¥0 | ¥0 |
| 通义 `text-embedding-v3` | ¥0.5 / 百万 token | **¥0.077** | ¥0.000029 |
| OpenAI `text-embedding-3-small` | ¥0.15 / 百万 token | **¥0.023** | ¥0.000009 |

结论：**索引一次不到一毛钱**，每查询不到十万分之三分。真正的成本约束不是钱，而是：

· 闸门与上限照抄 ASR 那套：`COURSE_EMBED_ALLOW_PAID=1` 才允许付费 provider，
  `COURSE_EMBED_MAX_COST_CNY`（每次运行的上限）超了就停；
· 重发只重算改动的小节（指纹缓存），所以日常增量成本接近 0；
· 若将来做"每次查询都语义检索"，每天几百次查询也仍然是**分级钱**——但延迟会加在读者身上，
  所以仍然只在回退时才用。

## 6. 存储与失效

· `<站点目录>/embeddings.json`：`{ model, dim, createdAt, items: { "<slug>#<sectionId>": { fingerprint, vector } } }`；
· 随发布原子写（与 `library.json` 同一套 `writeJsonAtomic`），**不进公开索引**
  （向量体积大、对读者无用，MCP 也不需要）；
· 校验：读取时比对小节指纹，不一致就用词面结果（陈旧向量绝不参与排序）。

## 7. 怎么跑

```bash
node tools/semantic-eval.mjs ~/.course-worker/site/library.json            # stub，免费，验证管道
node tools/semantic-eval.mjs <library.json> --json                        # 机器可读
PROVIDER=dashscope COURSE_EMBED_ALLOW_PAID=1 COURSE_EMBED_MAX_COST_CNY=1 \
  node tools/semantic-eval.mjs <library.json>                             # 接真模型（需实现 embed()）
```

接真模型只需要实现 `makeEmbedder()` 里的一个分支（价格表已在 `PRICES` 里）。

## 8. 决策标准（先说清，免得事后找理由）

把语义层合入默认路径，必须同时满足：

1. **冻结留出集**上 top3 ≥ 3/4 且 top1 ≥ 2/4（现在是 1/4 与 0/4）；
2. 每查询延迟 < 300ms（含 embedding 调用），且服务不可用时能退回词面（有测试）；
3. 一个月总成本 < ¥1（按当前规模，索引 + 查询）；
4. 结果里带相似度与"按语义近似召回"的标注，读者能判断可信度。

任何一条不满足，就只保留"实验开关"，不改进默认路径。

## 9. 真模型那一跑的结果（2026-09-28，百炼 text-embedding-v3）

```

开发集： top1 3/3，  top3 3/3
冻结集： top1 3/4，  top3 4/4      ← 词面检索是 0/4 与 1/4
实际用量：168,077 token / 42 次调用 → 实际花费 ¥0.0840（上限 ¥1）
延迟：查询向量化 冷 323ms / 热 254ms（含 TLS 首连），本地检索 7ms/次
```

| 问法 | 词面 | 语义（top1 / top3） |

| 自然人为什么会成为国际刑法责任主体 | 未命中 | **命中** 国际刑法学 09-09（语料里写的是"个人刑事责任的确立"） |
| 刑罚过重会不会让法官改变罪名的解释 | 未命中 | top1 错、**top3 命中** 刑事执行法 09-21（"以刑制罪"） |

## 10. 结论：按 §8 的预先标准逐条对照

| 标准 | 结果 | 判定 |
|---|---|---|
| 1. 冻结集 top3 ≥3/4 且 top1 ≥2/4 | top3 **4/4**、top1 **3/4** | ✅ 达标 |
| 2. 每查询 <300ms，服务不可用能退回词面 | 热 254ms 达标；冷启动 323ms（含 TLS 首连）略超 | ⚠️ 基本达标（且它是**回退路径**，只在词面零命中时走；回退逻辑要带测试） |
| 3. 月成本 <¥1 | 全量索引 ¥0.084 一次性；每查询 ¥0.000029 | ✅ 达标（当前规模下几乎可忽略） |
| 4. 结果带相似度与"按语义近似召回"标注 | 尚未实现（属于合入时的要求） | ⏳ 合入前必须做 |

**结论：值得做，但按"低置信回退"的形态做，不动默认路径。** 四件事**已经做完并上线**：

1. **向量存储与失效** ✅ `site/embeddings.json`：一小节一条向量，键 `<slug>#<sectionId>`，
   值带内容指纹；指纹没变的小节复用旧向量（`course embed` 实测第二次 387 复用 / 0 新算 / **¥0**）。
   指纹对不上或课次已不在库里 → 那条向量直接跳过。
2. **回退接线** ✅ 只在字面检索**一条都没命中**时走一次；命中带 `similarity` 与 `semantic:true`，
   站点页面与 MCP 都会写明"字面没有命中，以下按语义近似召回"；`lexicalTotal` 如实报 0。
3. **可用性降级** ✅ 查询向量化有**硬超时**（默认 1s，Promise.race 兜底，不依赖 fetch 是否尊重 signal）；
   服务慢/挂/限流/断网一律静默退回"没有结果"，第一次失败写一行日志（排障靠它）。
4. **测试** ✅ `packages/notes-mcp/src/semantic.test.mjs` 10 个用例：指纹失效、门槛、降级、
   标注、进程内缓存、索引 mtime 重载、以及**端到端**（服务 → 真实回退 → 召回成功）。

### 10.1 上线后的实测（2026-09-28 晚）

| 场景 | 结果 |
|---|---|
| 管理进程 `/api/search?q=轻罪前科怎么处理` | `semantic.used=true`、`lexicalTotal=0`、返回 4 条；top1 = 刑事执行法 09-14「六、轻微犯罪记录封存制度」**相似度 0.662**，片段取自正文 |
| 同进程 `/api/search?q=罪刑法定`（字面能命中） | `semantic.used=false`，5 条全部来自字面检索——**语义一次都没被调用**（成本与延迟纪律） |
| 公开进程同一个句子 | `semantic.enabled=false`、0 条：公开进程刻意不加载任何机密，语义回退**默认关闭** |
| 整次请求耗时 | 455ms（含查询向量化 ~250–300ms），远低于 1s 预算 |

**要不要在公开站点也打开**：需要在 `env.public` 里放一把**只给 embedding 用**的 key
（`COURSE_EMBED_API_KEY`）——那会往公开进程里引入一个机密，是有意的取舍；
每查询多约 0.3 秒、约 ¥0.00003。不改也自洽：公开站点继续零机密、零外部依赖，
语义能力只给管理进程与本地 stdio 客户端（它们本来就有 key）。
