# 14 · 产物的角色与边界

> 六种产物各有各的读者与用途。**它们之间只允许单向引用**：单课笔记是唯一的事实来源，
> 其余都是它的派生视图。边界写清楚，才能回答"这条结论该信哪一份""源改了谁要重做"。

## 1. 一张表说清六种产物

| 产物 | 回答什么问题 | 粒度 | 谁读 | 更新触发 | 绑定的来源 | **不做什么** |
|---|---|---|---|---|---|---|
| **单课笔记** `notes/<课程>/<课次>.md` | 这节课讲了什么 | 一节课 | 读者、AI | `course notes` 重跑 | 本身是来源（绑定转录与课件） | 不做跨课次对照 |
| **简报** `brief.json` | 这节课大概在讲什么（一句话 + 三条要点） | 一节课（<200 字） | 手机上的读者（推送、列表） | 正文内容变了 | `sourceChecksum`（正文指纹） | 不引入正文没有的事实；不下结论 |
| **一页纸** `onepage.json` | 复习时只看这一页 | 一节课（一张 A4） | 读者（打印/速览） | 正文内容变了 | `sourceChecksum`（规范化指纹） | 不做新事实；不做跨课次；不做练习题 |
| **章级整合** `integrations/<课程>-<主题>.md` | 这一章（几节课）在讲什么：概念怎么推进、争点各节课怎么回答 | 一章（2—6 课次） | 读者（复习）、AI | 参与课次的内容指纹变了 | 每个课次的 `contentFingerprint` + **逐行出处**（课次 + 小节 id） | 不重写单课正文；不写没有出处的行；不替读者下结论 |
| **个人批注** localStorage + 导出 JSON | 我关心/我标过什么 | 一段文字 | 只有读者自己 | 读者自己 | 锚点（id / 小节 / 前后文 / 内容指纹 / 正文版本） | **不上传**、不参与检索、不影响他人、不进任何发布产物 |
| **知识图谱**（概念/法条/案例索引） | 哪些概念反复出现、它们在哪几节 | 全局（跨课程） | 读者、AI | 概念清单变了 | `metadata` + 落点锚点 | 不给结论、不给证据——它是**入口**，不是依据 |

## 2. 引用方向（单向）

```
单课笔记  ←──  简报、一页纸、章级整合、个人批注      （都指回课次与小节）
   ↑
知识图谱  ←──  概念/法条/案例 + 锚点                （只是入口，不承载论证）
```

· 派生视图**只能**引用笔记，笔记不引用它们——否则一改一改就成环，谁是最新版本说不清；
· 章级整合的每一行都必须能点回"哪一节课的哪一节"（B2 的 `checkIntegrationSources` 强制）；
· 检索（站点搜索、MCP）只把笔记当事实，其余产物**不参与检索排序**（否则同一件事会被数两遍）。

## 3. "待核/不确定"的传递规则

正文里标了"待核"的地方（转录听不清、术语存疑），下游产物**不能把它写成结论**：

· 简报/一页纸：要么照写标记，要么整段不提；不能只说结论；
· 章级整合：待核标记**原样继承**并标注课次与行号（B2 已实现），并在页尾提醒"这些点在单课里就没有定论"；
· 检查器：`checkMarkerPropagation`（A8）会在正文有标记、而下游产物一个都没有时报警。

## 4. 失效与重做（C1 的前置）

每个产物都在自己的 JSON 里声明**它绑在哪一版源上**：

| 产物 | 绑定字段 | 源变了怎么办 |
|---|---|---|
| 简报 | `sourceChecksum` | 发布时 `checkBriefBinding` 判定不同源 → **中止发布**（宁可这次不发） |
| 一页纸 | `sourceChecksum` | 发布时 `verifyDerived` 判定不同源 → 中止发布 |
| 章级整合 | 每课次 `contentFingerprint` | 标记为 stale（**不自动重生成**：重生成要么花钱、要么需要人确认主题范围）；`course integrate` 重跑即可 |
| 知识图谱 | 由 `metadata` 现算 | 随发布自动更新 |
| 个人批注 | 锚点里的 `revision` + 内容指纹 | 定位失败时**保留记录**并提示（A5），绝不静默删除 |

## 5. 成本边界（哪些是免费的）

| 产物 | 是否调用模型 | 说明 |
|---|---|---|
| 单课笔记 | 是（贵） | 大纲 → 节点 → 写作 → 审查 → 拼装 → 终审 |
| 简报 / 一页纸 | 是（便宜） | 一次调用，输入是已成稿的笔记 |
| 章级整合 | **否**（当前） | 确定性抽取：概念对照、问题线、时间线、待核继承、出处；`--live`（模型补连接性文字）**未开**，开了要单独评审与预算 |
| 知识图谱 / 个人批注 | 否 | 派生 / 本地 |

## 6. 边界在代码里的落点

| 规则 | 落在哪 |
|---|---|
| 整合每行必须有出处 | `packages/notes/src/integration.mjs` 的 `checkIntegrationSources`（error 级会让命令返回 1） |
| 简报/一页纸必须与正文同源 | `@course/notes` 的 `checkBriefBinding`、`@course/publish` 的 `verifyDerived` |
| 待核必须贯通 | `packages/notes/src/quality.mjs` 的 `checkMarkerPropagation` |
| 批注只存本地 | `packages/publish/src/reader.mjs`（localStorage + 导出 JSON，无任何上传接口） |
| 检索只认笔记 | `packages/notes-mcp/src/service.mjs`（数据源只有发布库的记录，不含整合/批注） |
