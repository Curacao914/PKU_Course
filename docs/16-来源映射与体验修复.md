## 1. 来源映射做了什么

### 1.1 数据结构（复用现状，不另建一套）

`onepage.json` 里新增一个轻量结构，页面渲染与回跳定位都用它：

```json
{
  "version": 1,
  "note": { "slug": "notes/刑事执行法/2026-09-21第5-6节", "checksum": "<规范化指纹>" },
  "onepageChecksum": "<规范化指纹>",
  "generatedBy": "model | lexical-overlap",
  "entries": [{
    "block": "ob-89a604be",
    "label": "《刑法》第5条：刑罚的轻重……",
    "sections": [{ "id": "二-罪行关系的双重逻辑与罪刑均衡原则", "title": "二、罪行关系的双重逻辑与罪刑均衡原则",
                   "quote": "应当与犯罪分子所犯罪行和承担的刑事责任相适应", "match": "quote" }]
  }]
}
```

- **块 ID**（`data-ob`）由块自身**规范化文本**算出（FNV-1a 32 位，9 位十六进制带 `ob-` 前缀），
  与小节指纹同一口径：改标点不换 ID、改内容才换 ID（旧映射随之自然失效）。
- 块切法只有一处实现（`onepageBlocks`）：渲染时包 `data-ob`、映射时定位、核对时比对都用它。
  相邻的表格/列表块会合并——同一个问题被切成两条映射，读者会看到两个"看原文"。
- 指纹用既有的**规范化**口径（`markdownChecksum`），没有混用原始字节 hash。

### 1.2 四条核对（发布链路里做，因为只有那里同时握着正文）

| 核对 | 不过会怎样 |
|---|---|
| 身份：映射记的是不是这一篇 | 整份不用 |
| 版本：源正文/一页纸指纹对不对 | 整份不用（不许留"精确来源"的假象） |
| 小节存在：id 在不在源文里 | 丢掉这一条 |
| **摘录确实逐字在这一节里**（忽略空白） | 丢掉这一条 |

小节存在只证明链接有效，**不证明它支撑这个要点**——所以每条映射都必须带一小段源文摘录并逐字核对。
核对不过就退回"查看整篇笔记"，绝不生成看着精确的错误链接；未定位不阻塞发布。

### 1.3 三条生成路径

1. **新一页纸（模型）**：schema 增加 `sourceMap`，提示词附上**可用小节清单**（id + 标题），
   模型只能从里面挑 id、给一小段块内原文当定位提示，程序解析成块 ID 并盖章。
   模型编造的小节 id 在写盘时就筛掉。
2. **已发布一页纸（免费路径 `course sourcemap`）**：只认两种可核对的对应——
   逐字引用（`match: quote`）与块里原样点了某一节的标题且唯一（`match: title`，≥4 字）；
   摘录都取那一节正文里的原话。默认干跑，`--write` 才写回，`--show` 列出逐对结果供人工核对。
3. **正文改过之后**：受影响映射在下次发布时重新核对，对不上就整份退回整篇入口；
   **浏览页面不触发任何重建**（渲染侧只做"块还在不在、小节还在不在"的轻核对）。

### 1.4 阅读往返

- 阅读模式里每块后面一个小而清楚的入口：单来源是「看原文 · 小节名」，多来源是紧凑弹出列表；
  未定位的块不硬指，页面底部如实写「本页有 N 个要点未能定位到具体小节（未做依据核对）」+ 查看整篇笔记。
- 点「看原文」记下"哪一页的哪一块、滚到哪"；原文那边**只有地址校验通过**（站内 `/onepage/`、
  无协议无双斜杠、且与当前这一篇对得上）才显示「返回一页纸」——直接打开原文时没有这个按钮。
- 回一页纸落回**原来那一块**并轻量高亮；浏览器后退同样落回；往返不重置字号、纸色、深浅。
- **A4 预览与打印里没有这些交互控件**（`data-sheet-mode="a4"` 与 `@media print` 双重隐藏），
  纸张不会被来源入口撑成多页；阅读模式不受纸张约束。

## 2. R1–R3 三项缺陷

| 缺陷 | 根因 | 现在 |
|---|---|---|
| R1 空标记入口报错 | 笔记页脚本里的 handler 调用另一个闭包里的 `toast`（`toast is not defined`） | handler 移到有 toast 的那段脚本；零标记时给可读提示；从一页纸带 `#railMarks` 进来也覆盖空状态 |
| R2 复制小节链接失败仍报成功 | 不等 `clipboard.writeText` 完成就改按钮文字 | 复制成功/失败只有一处判断（与"复制整篇 Markdown"共用）；被拒或没有剪贴板 API 时按钮保持 "#" 并给出可手工拿走的文本；地址栏先改，阅读位置不丢 |
| R3 近似词法结果误标为精确命中 | `badge()` 把所有非语义结果都写成"精确命中" | 四档：精确匹配（查询串整串原样出现在小节标题或片段里）/ 关键词匹配 / 近似词匹配（写明原词→替换词）/ 语义近似（相似度不当正确率） |

### 6.2 这一轮**没做**（如实列出）

- **收起方向的过渡**：浮层收起是瞬时的。原因是闭着的浮层若留在布局里（`opacity:0`），
  会在手机上把整页撑出横向滚动（实测 390px 视口 `scrollWidth 416`）。要做"淡出再隐藏"，
  需要在脚本里加一个 closing 状态与延时——值得做，但要连着两个脚本一起改，放在下一轮。
- **字号 100%/140% × 四种底色的完整对照**：对照图覆盖了浅色/深色与 100%/140%，
  豆沙绿、牛皮纸、灰色三档底色只做了变量一致性检查，没有逐档出图。
- **"展开来源 → 跳原文 → 返回"的短录屏**：任务书要的是录屏，本轮只出了三张连续截图
  （`docs/shots/sourcemap/onepage-sample-*.png`：一页纸 → 原文落点 → 返回后）。录屏需要
  一台能录屏的环境，我在服务器上只能用无头浏览器出图。
