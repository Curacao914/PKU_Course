## 3. 历史正文修订保护已上线

系统会比较三份正文：

1. 正式发布库 `record.markdown`
2. replay `transcript/<lesson>.md`
3. `lesson-state.json -> lesson.finalNote.markdown`

状态包括：

- fresh
- source-missing
- source-state-drift
- unpublished-change
- untracked

普通 republish 遇到 `note.md != finalNote` 默认中止。

显式历史基线同步：

```
course source-sync --replay-key <键> --course <课程> --lesson <课次> --yes
```

会先备份 note/state/summary，再以当前正式正文对齐 replay 源与 finalNote；不模型、不发布、不通知。
