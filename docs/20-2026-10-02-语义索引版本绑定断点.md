## 5. 当前阶段的产品路线：先积累，不做期末整合版

用户明确说明：**现在仍处于学期初，最后整合版笔记暂时不需要。**

因此不要过早把课程结构冻结成“期末总复习稿”。

当前更合适的方向是：

### 学期中持续积累层

每节课照常生成单课笔记，并逐步沉淀：

- 老师个人观点；
- 老师明确赞成 / 保留 / 批评的学说；
- 争议点；
- 案例；
- 法条；
- 期末论文 / 延伸研究线索；
- 跨课次重复出现的概念与问题；
- “本周对前几周内容的修正 / 推进”。

这些内容应当以**轻量索引 / 元数据 / 可回溯标签**的形式增长，不急着写成长篇综合叙事。

### 中后期再生成 Course-level exam views

到课程中后段或期末复习时，再基于已经积累的结构化材料生成：

- 课程全景图；
- 老师观点总表；
- 争议点对照；
- 案例串联；
- 法条体系；
- 可能考点与论文线索；
- 最终整合版笔记。

原则不变：

- 单课笔记是唯一事实源；
- 课程级视图是派生物；
- 每个结论都应能回溯到具体课次 / section；
- 优先复用现有 integration manifest / metadata / MCP / source anchors；
- 不新增第二套事实数据库。
