### PR #8：Semantic index revision binding

已合并：

```
41b0f34810f904f12666da9b33b24d1bac98c4b9
```

核心实现：

- `embeddings.json` 新增 `libraryRevision`；
- 查询侧先做整库 revision 校验：
  - match → 可用；
  - unbound → `library_revision_unbound`，整份禁用；
  - mismatch → `library_revision_mismatch`，整份禁用；
- stale / unbound 时不再发查询 embedding API 请求；
- 构建侧仍可把旧索引当缓存读取；
- 真正复用必须逐 section fingerprint 一致；
- `course embed` 开始时记录 library revision；
- 最终写索引前短暂拿 publish lock，再次核验 revision；
- 长向量化期间若正文发布发生变化，拒绝提交错误绑定的新索引；
- 已付费向量继续留在 cache，下次重跑不会重复付费；
- 搜索响应新增：
  - `semantic.enabled`
  - `semantic.available`
  - `semantic.reason`
- UI 区分：
  - 语义未启用；
  - 索引暂不可用；
  - 已启用但没有相似结果；
- semantic index 已纳入 `artifacts` 的 fresh / stale / unbound 依赖账本；
- public semantic 仍默认关闭，没有向公开进程加入 AI secret。
