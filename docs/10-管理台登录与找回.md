# 10 · 管理台登录与找回

> 管理台地址：**https://course.law-tech.dev/admin**
> 本文是**登录凭据的找回手册**——管理台密码是你自己设的，忘记时按 §3 操作即可。

## 1. 两种登录方式（任一即可）

| 方式 | 是什么 | 什么时候用 |
|---|---|---|
| **登录密码** | 你自己设的密码（≥8 位），只存 scrypt 哈希 | 日常使用 |
| **主令牌** | 服务器环境变量 `COURSE_ADMIN_TOKEN` 里的那串随机值 | **忘记密码时**的万能钥匙 |

在管理台顶部的「管理令牌」输入框里填其中任意一个，点「保存令牌」，浏览器会记住。

## 2. 修改密码

**方式 A：管理台里改（推荐）**
管理台 →「设置」→「登录密码」→ 填新密码 →「保存新密码」。
（改完界面会自动用新密码继续，不用重新登录。）

**方式 B：在服务器上改**
```bash
ssh -i ~/.ssh/lawtech-tencent ubuntu@124.222.111.108
cd ~/course-runtime

# 推荐：从标准输入读，密码不会出现在 ps 与 shell 历史里
node apps/worker/bin/course.mjs admin-passwd --set-stdin
# （回车后输入新密码，再按 Ctrl-D）

# 或者直接写在命令里（方便，但会留在 shell 历史里）
node apps/worker/bin/course.mjs admin-passwd --set '你的新密码'
```

## 3. 忘记密码了怎么办（找回手册）

### 3.1 主令牌还在（绝大多数情况）

```bash
# 1) 在服务器上取出主令牌
ssh -i ~/.ssh/lawtech-tencent ubuntu@124.222.111.108 \
  'grep COURSE_ADMIN_TOKEN ~/.course-worker/env'
```

输出形如 `COURSE_ADMIN_TOKEN=abc123…`，把等号后面那串粘进管理台的输入框即可登录。

```bash
# 2) 登录后到「设置 → 登录密码」重新设一个自己记得住的密码
```

### 3.2 主令牌也丢了

在服务器上重设一个主令牌（会重启站点服务）：

```bash
ssh -i ~/.ssh/lawtech-tencent ubuntu@124.222.111.108 \
  'sed -i "s|^COURSE_ADMIN_TOKEN=.*|COURSE_ADMIN_TOKEN='"$(openssl rand -hex 32)"'|" ~/.course-worker/env && \
   systemctl --user restart course-site && \
   grep COURSE_ADMIN_TOKEN ~/.course-worker/env'
```

### 3.3 只想要一个干净状态（清掉密码）

```bash
ssh -i ~/.ssh/lawtech-tencent ubuntu@124.222.111.108 \
  'cd ~/course-runtime && node apps/worker/bin/course.mjs admin-passwd --clear'
```

清掉之后**只能用主令牌登录**。想再设密码，用 §2 的方式 A 或 B。

### 3.4 看当前是什么状态（不看密码本身）

```bash
ssh -i ~/.ssh/lawtech-tencent ubuntu@124.222.111.108 \
  'cd ~/course-runtime && node apps/worker/bin/course.mjs admin-passwd --status'
```

会告诉你：密码是否已设置、主令牌是否存在、密码最后修改时间、密码文件的路径。
**密码本身读不回来**——只存哈希，这是有意的。

## 4. 安全约定

- **密码只存 scrypt 哈希**（salt 随机、参数写在文件里），明文不落盘、不进日志；
  服务器管理员也读不回你的原密码，只能重设。
- **限流**：同一来源 IP 连续 5 次凭据错误 → 拒绝 5 分钟（错误密码与错误的令牌一样计）。
- **界面改不了密钥**：管理台只能改"调参"（字数预算、并发、成本窗口…）；
  `DASHSCOPE_API_KEY`、`COURSE_AI_API_KEY`、`PKU_*` 等**只能从服务器环境变量读**。
- **未配置主令牌且没设密码时**：管理台整体返回 503（fail-closed），不会"没配就等于开放"。

## 5. 速查表

| 想干什么 | 命令 |
|---|---|
| 取主令牌 | `grep COURSE_ADMIN_TOKEN ~/.course-worker/env` |
| 重设密码（不回显） | `course admin-passwd --set-stdin` |
| 重设密码（图快） | `course admin-passwd --set '新密码'` |
| 清掉密码 | `course admin-passwd --clear` |
| 看登录状态 | `course admin-passwd --status` |
| 换主令牌 | 改 env 里的 `COURSE_ADMIN_TOKEN` → `systemctl --user restart course-site` |

相关文件：

| 文件 | 内容 |
|---|---|
| `~/.course-worker/env` | 主令牌与所有密钥（权限 0600） |
| `~/.course-worker/admin-password.json` | 密码哈希（权限 0600；删掉它等于清密码） |
| `apps/site/src/admin.mjs` | 鉴权、限流、/`api/admin/password` 接口 |
| `packages/core/src/admin-auth.mjs` | 哈希与校验实现（站点与 worker 共用） |
